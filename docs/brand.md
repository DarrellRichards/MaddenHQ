# Brand

## Logo

- Full wordmark: [`/public/brand/maddenhq-logo.png`](../public/brand/maddenhq-logo.png)
- Mark / favicon: [`/public/brand/maddenhq-mark.png`](../public/brand/maddenhq-mark.png)

The stylized **M** uses a red chevron (`#D32F2F`) over primary blue legs (`#4B5F91`). Prefer the full wordmark in navigation and the marketing hero.

## Colors

| Token | Hex | Usage |
| --- | --- | --- |
| Background | `#FFFFFF` | App surfaces |
| Primary | `#4B5F91` | Brand chrome, headings, links |
| Accent | `#D32F2F` | Primary CTAs, active nav, emphasis |

Derived tokens live in `src/app/globals.css` (`--primary-soft`, `--primary-border`, `--muted`).

## Typography

- Display: Chakra Petch (sporty geometric, wide tracking)
- Body: Manrope

Do not introduce Inter / Roboto / Arial as display faces.
